# 노션 차단 때문에 접속이 안 돼서 쓸 수 있는 대체품이 있다면? My Notion

Notion처럼 쓰는 **개인용 지식 관리 웹앱**이에요. 설치할 것 없이 **HTML 파일 하나**로 동작해요.

페이지와 블록으로 글을 쓰고, 표·단·그래프·데이터베이스(표·보드·갤러리·캘린더·리스트)·템플릿·잠금 화면·인쇄/PDF까지 한곳에서 쓸 수 있어요.

> 현재 버전: **v2.2.0**

---

## 바로 써 보기

**👉 [My Notion 열기](https://YOUR-ID.github.io/my-notion/)**

링크를 열면 바로 쓸 수 있어요. 이 방식에서는 내용이 **지금 쓰는 브라우저에만** 저장돼요.

다른 기기로 옮기려면 사이드바 **💾 전체 백업**으로 ZIP을 받은 뒤, 다른 기기에서 **📥 가져오기**로 넣으면 돼요.

## 두 가지 사용 방법

| | 브라우저에서 바로 쓰기 (GitHub Pages) | claude.ai 아티팩트로 쓰기 |
|---|---|---|
| 준비 | 링크만 열면 끝 | claude.ai 계정 필요 (아래 안내) |
| 저장 위치 | 이 브라우저 (IndexedDB) | 내 claude.ai 계정 |
| 여러 기기·탭 동기화 | ✗ (백업 ZIP으로 옮기기) | ✓ 실시간 |
| 그림·파일 첨부 | 약 10MB까지 | 20MB까지 (PPT·Word·Excel 등은 100MB) |
| PPT·Word·Excel·한글 첨부 | ✗ | ✓ |
| 인쇄 · PDF 저장 | ✓ | ✓ |
| 잠금 화면 | 이 브라우저에서만 | 같은 계정의 모든 기기에 함께 |

### claude.ai 아티팩트로 쓰기 (동기화까지 모두)

1. 이 저장소의 `index.html`을 내려받아요. 오른쪽 **Releases**에서 버전별로 받을 수도 있어요.
2. [claude.ai](https://claude.ai)에서 새 대화를 열고 파일을 첨부해요.
3. 아래 문장을 그대로 보내요.

   ```
   첨부한 파일을 내용 수정 없이 Artifact로 게시해줘.
   capabilities는 {"db": {}, "user": {}, "assets": {}, "downloads": true}, icon은 "notes"로 해줘.
   ```
4. 게시된 아티팩트를 열면 끝이에요. 내용은 내 계정에 저장되고, 같은 계정으로 연 다른 기기와 바로 동기화돼요.

> capabilities를 빼먹으면 계정 저장·동기화·첨부·PDF 저장이 동작하지 않아요.

### 새 버전으로 업데이트하기 (내용은 그대로)

- **claude.ai:** 새 `index.html`을 첨부하고 "첨부한 파일로 기존 My Notion 아티팩트를 내용 수정 없이 업데이트해줘. capabilities는 지금 그대로 유지해줘."라고 보내요. 내용은 아티팩트 파일이 아니라 계정 저장소에 따로 있어서, 코드를 바꿔도 페이지·첨부·버전 기록·휴지통은 그대로예요. 업데이트한 뒤에는 열려 있던 모든 기기와 탭을 새로고침하세요.
- **GitHub Pages:** 같은 주소를 새로고침하면 새 버전으로 열리고, 브라우저에 저장된 내용은 그대로 남아요.

## 주요 기능

- **블록 편집:** `/`로 블록 추가. 제목, 목록(글머리·번호·할 일·토글), 인용, 콜아웃, 코드, 구분선 9종, 이미지, 파일, 하위 페이지를 쓸 수 있어요. 마크다운 단축 입력과 여러 블록 선택·이동도 돼요.
- **서식:** 글자 서식(굵게·기울임·밑줄·취소선·색·링크)과 블록 서식(정렬·크기·글꼴·줄 간격·여백·상자)을 줄 수 있어요.
- **표:** 크기 조절, 칸·행·열 서식과 테두리, 여러 칸 선택, 칸 합치기·나누기, 엑셀 붙여넣기를 지원해요.
- **단 나누기:** 2~6단으로 나눠 쓰고, 구분선 모양·색·간격·단별 서식을 바꿀 수 있어요.
- **그래프:** 막대·꺾은선·영역·원형·도넛·분산형·방사형. 데이터는 표나 데이터베이스와 연결할 수 있고, SVG·PNG로 저장해요.
- **데이터베이스:** 표·보드·갤러리·캘린더·리스트 보기. 속성은 선택·날짜(기간·시각)·수식·관계형·롤업 등을 쓸 수 있고, 항목마다 속성을 따로 둘 수 있어요. 여러 기준 정렬, 필터, 상태·태그 일괄 삭제, 새 항목 템플릿도 있어요.
- **캘린더:** 토요일·일요일 색 표시, 날짜 칸과 일정을 색으로 강조, 기간 일정 표시.
- **템플릿:** 기본 템플릿 14종(회의록·실험 노트·논문 리뷰 등)이 있고, 내 페이지를 템플릿으로 저장할 수 있어요.
- **인쇄·PDF·내보내기:** 쪽 미리보기와 PDF 저장, Markdown 내보내기, Notion용 ZIP 내보내기, 전체 백업 ZIP과 가져오기.
- **잠금 화면:** 비밀번호로 화면을 잠그고 자동 잠금도 설정할 수 있어요.
- **버전 기록·휴지통:** 페이지마다 10분 간격 자동 보관(최대 50개), 지운 페이지는 30일간 보관해요.
- **사용설명서:** 앱 안 **설정 → 📖 사용설명서**에서 모든 기능을 검색할 수 있어요.

## 개인정보

- 이 앱은 내용을 **외부 서버로 보내지 않아요.** 내용은 브라우저 저장소나, claude.ai로 쓸 때는 본인 계정 저장소에만 저장돼요.
- 외부에서 불러오는 것은 백업 ZIP을 만들 때 쓰는 JSZip 라이브러리(cdnjs) 하나뿐이에요.
- 잠금 화면은 **화면을 가리는 잠금**이에요. 데이터 자체를 암호화하지는 않아요.
